# User 人设与世界书管理 (st-persona-wardrobe)

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](./LICENSE)
![Type: UI Extension](https://img.shields.io/badge/SillyTavern-UI_Extension_(纯前端)-success)
![AI-Assisted](https://img.shields.io/badge/AI--Assisted-人工审查与多端实测-6366f1)

专为 **SillyTavern**、**Luker** 与 **TauriTavern (TRT)** 全端（桌面端 & Android / iOS / HarmonyOS 移动端）设计的 User 人设（Persona）分类管理、状态快照与关联世界书增强扩展。

原位接管酒馆顶栏原生人设抽屉（`#PersonaManagement`），并保留一键切换原生平铺列表与独立双栏管理窗口。

---

## 多宿主兼容矩阵

| 宿主前端 | 兼容特性 |
|---|---|
| **SillyTavern** (`v1.14+` ~ `v1.19+` / Termux) | 原位接管 `#PersonaManagement`、磁盘 `/api/avatars/get` 去重过滤、旧版头像直链自动降级（无需先打开原生列表）、防 `SETTINGS_UPDATED` 滚动回顶 |
| **Luker** (`funnycups/Luker`) | 识别并去重合并 `character.data.extensions.luker.dedicated_personas` 卡内专属人设、移动端 `html` transform 视口定位修复、阻止抽屉穿透收起 |
| **TauriTavern / TRT** (`Darkatse/TauriTavern`) | 等待 `__TAURITAVERN__.ready` 延迟激活、全量异步 `<dialog>` 输入/确认弹窗（规避原生 WebView 禁用 `prompt`/`confirm`）、接入 `__TAURITAVERN_HANDLE_BACK__` 安卓/鸿蒙侧滑返回手势、支持 `api.worldInfo.openEntry` 条目深链定位、适配 `download-bridge` 异步导出与软键盘视口压缩 |

## 核心功能

### 1. 原位接管人设栏目 & 进入新聊天分组选人设
- **原位接管开新聊天选人设弹窗**：进入新聊天（或角色绑定了多个人设弹出选人设框、点击角色连接按钮）时，自动用带分组与搜索的人设选择器替代酒馆原生简陋头像框——默认展示「★ 当前角色绑定」，同时支持随时切到「全部 / 收藏 / 自定义分组」跨组选人设、搜索、切换列表/宫格视图，以及一键直选某套**状态快照**；在「开始新聊天？」确认框内也支持提前预选新档 User（即使该角色未绑定多个人设）。
- **按角色自动成组 & 其他角色绑定折叠防刷屏**：当前正在聊天的角色绑定组单独置顶直出；所有其他非当前聊天的角色组默认自动收进「`🎭 其他角色绑定`」总文件夹（仅占 1 行，点开再看各角色子组），彻底告别多角色连线刷满列表顶部。
- **两级嵌套分组（`大类/子组`）& 已有分组随时加/改大类**：自定义分组支持「`📁 大类 -> 📂 子分组`」两级文件夹结构；不仅新建分组时可选/新建上级大类，对**已建好的自定义文件夹**点击右侧「`✏️`」或「`👤+`」也能随时选择已有大类、一键「`+ 新建大类`」或移回一级独立分组，点击大类右侧「`✏️`」还支持一键勾选多个已有独立文件夹批量并入该大类；同一个 User 可同时放入多个分组；工具栏内置一键「`收展`」全折叠/全展开按钮。
- **带搜索默认多选的建组/管组员弹窗**：点击「`+ 新建组`」或分组右上角「`👤+`」即可在同一个弹窗内实时搜索、按状态筛选、整行点击默认多选勾选组员（支持 `Shift` 连选且不跳滚动条）。
- **多选批量管理**：开启「多选」即可一次性将多个人设批量加入分组、绑定角色卡、设置主世界书、收藏、导出分享包或安全批量删除（支持 `Shift` 连选与分节全选）。
- **排序、调序与三种视图切换**：支持按 `默认 / 最近使用 / 聊天时长 / 聊天档数 / 收藏优先 / 名称 A-Z` 排序，自定义分组支持 `置顶 / 上移 / 下移`，支持 **标准双行 / 紧凑单行 / 头像宫格** 三种视图切换，并自动记忆各分组与右栏模块的折叠状态。
- **通用图床与云端头像兼容**：自动穿透懒加载透明占位符（`1x1 GIF`）并识别第三方图床/美化扩展头像，内置 `⋯` 更多菜单支持直接上传、更换与同步云头像。
- **新版本自动提醒与一键原位更新**：启动时静默检测仓库更新（可在扩展设置中开关），有新版本时在人设栏顶部醒目提示并支持**「一键更新 + 自动清浏览器缓存」**，无需每次手动翻进扩展管理查看。

### 2. User 变体克隆、人设分享包 & 状态快照预设
- **状态快照**：一键把当前人设描述、主世界书（含各条目启用/常驻开关）、附加世界书与随身设定保存为命名快照（如「日常态」「战斗态」「IF线」），随时一键切回。
- **单人设 / 多选「人设分享包」导入导出**：支持将单个或多选的多个 User（含 Base64 头像原图、原生描述、随身设定、状态快照及可选关联世界书）打包导出为独立分享文件发给好友，一键导入完整还原。
- **完整克隆变体**：支持将当前 User 或任意快照一键克隆为全新独立 User 档案（含头像复制）。

### 3. 使用足迹统计（聊了几个角色卡 · 几个聊天档 · 聊了多久）
- 实时统计当前聊天互动，并支持 **「扫描历史档」** 一键回溯酒馆内所有历史聊天记录，展示每个 User 聊过的角色卡数、聊天档数、消息轮数、累计活跃时长及按角色展开明细。

### 4. 主世界书 + 多本附加世界书 + 随身设定卡
- **世界书一键跳转 & 条目定位**：支持直接跳转到酒馆世界书编辑器（在 TauriTavern 下支持 `api.worldInfo.openEntry` 直接定位具体条目），附带左下角 **「← 返回人设」** 悬浮胶囊。
- **弹窗内快改条目**：无需离开当前页面即可搜索、开关、切换常驻/关键词触发或增删改世界书条目。
- **突破单书限制**：每个 User 可额外关联多本世界书并配置独立随身设定片段，支持 **「生效预览」** 查看本轮实际注入内容。

## 安装方式

### 方式一：通过 Git 链接在线安装（推荐，支持 SillyTavern / Luker / TauriTavern）
1. 打开酒馆顶部 **扩展（Extensions）** → **安装扩展（Install Extension）**。
2. 粘贴仓库地址：`https://github.com/Wellilam/st-persona-wardrobe`
3. 安装后刷新页面（或在 TauriTavern 中重新进入）即可直接使用。

### 方式二：放入本地扩展目录
将 `st-persona-wardrobe` 文件夹放入对应宿主的扩展目录：
- **SillyTavern / Luker**：`data/<用户名>/extensions/st-persona-wardrobe/` 或 `public/scripts/extensions/third-party/st-persona-wardrobe/`
- **TauriTavern (TRT)**：在应用内通过「安装扩展」填入 Git URL，或放入 TauriTavern 数据目录的 `data/<user>/extensions/st-persona-wardrobe/`

## 权限、数据读写与提示词注入边界

本扩展为**纯浏览器端 UI Extension**，明文源码无混淆，不包含也不依赖任何 Node.js 后端插件（`Server Plugin`）。具体运行边界如下：

| 维度 | 实际行为与边界说明 |
|---|---|
| **网络请求范围** | **浏览器端零外部联网、零遥测上报**。仅调用当前酒馆实例自身的同源接口：`/api/avatars/*`（读取/上传/删除头像）、`/api/worldinfo/*`（读取/保存世界书条目）、`/api/characters/*` 与 `/api/chats/*`（仅在你主动点击「扫描历史档」时本地统计使用足迹）、`/api/extensions/discover\|version\|update`（复用酒馆内置扩展接口检测是否有新版本及一键更新，可在扩展设置中随时关闭自动检查）。唯一会请求非 `/api/` 地址的场景是你的人设本身使用了外部图床 URL 且主动点击「导出分享包」打包该头像图片。 |
| **配置与数据存储** | 分组、标签、随身设定、状态快照与统计缓存统一保存在宿主 `extension_settings['st-persona-wardrobe']` 中；修改人设名称、描述、主世界书或角色连线时，按宿主标准机制同步至 `power_user.personas` / `persona_descriptions`（在 Luker 下同步兼容角色卡 `dedicated_personas`）。**绝不触碰 API Key、Cookie 或其他敏感凭证。** |
| **世界书与人设安全** | **绝不静默删除或覆盖你原有的原生人设与世界书**。编辑世界书条目采用「先读取最新整书数据 → 仅更新目标条目 → 写回」机制；导入分享包附带世界书时，仅在本地不存在同名世界书时补齐，绝不覆盖本地同名书；删除人设需经二次确认，且自动保护当前使用中与系统默认人设。 |
| **第三方图床只读兼容** | 为显示第三方美化/图床扩展绑定的云端头像，会只读匹配宿主 `extension_settings` 与浏览器 `localStorage` 中含 `avatar/persona/图床` 字样键名下的图片链接，**只读不写，绝不修改其他扩展数据**。 |
| **提示词注入拦截** | 注册了 `generate_interceptor`（`PersonaWardrobe_interceptGeneration`）：**仅当当前生效人设启用了「附加世界书」或「随身设定」且命中条件时**，才向本轮对话上下文插入对应设定片段（自动跳过 `quiet` 后台生成）。未使用附加书/随身设定时零额外注入。 |
| **禁用、清理与卸载** | 实现了 `onActivate` / `onDisable` / `onClean` 钩子：在扩展管理中**禁用**时，立即移除全部注入 DOM、事件监听、返回手势与生成拦截，恢复原生界面（默认保留已建分组配置）；点击卸载删除扩展目录不会删除你原有的酒馆原生人设与世界书。`manifest.json` 中的 `auto_update: true` 仅遵循酒馆标准扩展更新机制，不会在后台私自拉取执行外部脚本。 |
